Итоговый проект для курса "Go-разработчик с нуля"

были выполнены все задачи со звездочками, включая авторизацию
работа с токенами упрощена - берется просто md5 от пароля из переменной окружения `TODO_PASSWORD`
и после сравнивается токен. При необходимости легко усложняется алгоритм, потому как все вынесено в отдельные функции

код разделен на логичные пакеты

для корректной работы с переменными окружениями, чтобы не прописывать их, а чтобы брался из файла `.env`, 
используется дополнительная библиотека `github.com/joho/godotenv`

при необходимости есть Dockerfile в корне, чтобы можно было собрать готовый образ и запустить программу в контейнере<br>
собрать образ: `docker build . --tag antonkisselev/yp_go_final`<br>
запустить контейнер `docker run -p 7540:7540 antonkisselev/yp_go_final`
